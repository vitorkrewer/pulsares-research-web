# 09. Atalhos de Teclado e Paleta de Comando

O Pulsares Research prioriza fluxos controlados por teclado para que você navegue entre leitura, fichamentos e escrita sem interromper o raciocínio.

## Atalhos Globais da Aplicação

| Atalho | Ação |
| :--- | :--- |
| `Ctrl + K` / `Cmd + K` | Abre a **Paleta de Busca Global** (Obras, Notas, Citações e Projetos) |
| `Ctrl + B` / `Cmd + B` | Recolhe ou expande a barra lateral esquerda |
| `Ctrl + ,` / `Cmd + ,` | Abre as **Configurações** do aplicativo |
| `Esc` | Fecha modais ativos, menus ou sai do modo de foco |

## Atalhos na IDE de Projetos & Editor Científico

| Atalho | Ação |
| :--- | :--- |
| `Ctrl + S` / `Cmd + S` | Salva imediatamente o projeto ou fichamento ativo |
| `Ctrl + Z` / `Ctrl + Y` | Desfaz / Refaz alterações no editor científico |
| `Ctrl + Shift + 7` | Lista numerada no editor |
| `Ctrl + Shift + 8` | Lista com marcadores no editor |
| `Ctrl + Shift + B` | Bloco de citação longa recuada (ABNT) |

## Atalhos no Leitor PDF

| Atalho | Ação |
| :--- | :--- |
| `Seta Direita` / `PageDown` | Avança para a próxima página do PDF |
| `Seta Esquerda` / `PageUp` | Retorna para a página anterior do PDF |
| `Ctrl + +` / `Ctrl + -` | Aumenta ou reduz o nível de zoom da página |
| `Ctrl + F` | Localiza termos dentro do documento aberto |
